ABOUT CYBER SECURITY

Learn, Understand and Protect the Digital World

1. What is Cyber Security?

Cyber Security is the practice of protecting computers, mobile phones, networks, applications and data from digital attacks and unauthorized access.

It helps protect personal information, financial details and important digital systems.

2. Important Definitions

1. Network Security

Protecting computer networks from unauthorized access.

2. Information Security

Protecting information from unauthorized use or changes.

3. Ethical Hacking

Authorized security testing used to find and fix weaknesses in computer systems.

4. Malware

Malicious software designed to damage, disrupt or access computer systems without permission.

5. Firewall

A security system that monitors and controls incoming and outgoing network traffic.

6. Encryption

Converting readable information into a protected format so unauthorized people cannot understand it.

3. Types of Cyber Security

  • Network Security: Protects computer networks.
  • Application Security: Protects software applications.
  • Cloud Security: Protects cloud-based data and services.
  • Mobile Security: Protects smartphones and tablets.
  • Information Security: Protects important information.
  • Endpoint Security: Protects computers and connected devices.

4. CIA Triad

The CIA Triad is a basic model of information security.

Confidentiality

Only authorized people can access information.

Integrity

Information should remain accurate and unchanged.

Availability

Information and systems should be available when needed.

5. Common Cyber Threats

  • Phishing: Fake messages or websites that try to steal information.
  • Virus: Malicious software that can affect computer files.
  • Ransomware: Malware that locks or encrypts data and demands payment.
  • Spyware: Software that secretly collects information.
  • Password Attacks: Attempts to gain access to accounts.
  • Social Engineering: Tricking people into sharing confidential information.

6. Cyber Security Tools

  • Wireshark: Network traffic analysis.
  • Nmap: Authorized network discovery and security auditing.
  • Metasploit: Authorized security testing framework.
  • Burp Suite: Web application security testing.
  • Windows Defender: Helps protect computers from threats.

Use security tools only on systems you own or have clear permission to test.

7. Basic Cyber Security Programs

Program 1: Password Strength Checker

This program checks the length of a password.

password = input("Enter your password: ")

if len(password) >= 8:
    print("Password length is acceptable")
else:
    print("Password should have at least 8 characters")

Program 2: SHA-256 Hashing

This program creates a hash from text.

import hashlib

message = input("Enter a message: ")

result = hashlib.sha256(
    message.encode()
).hexdigest()

print("SHA-256 Hash:", result)

Program 3: Check HTTPS Website

This program checks whether a URL starts with HTTPS.

website = input("Enter website URL: ")

if website.startswith("https://"):
    print("HTTPS connection URL")
else:
    print("HTTPS is not specified in this URL")

8. How to Stay Safe Online

  1. Use strong and unique passwords.
  2. Enable two-factor authentication.
  3. Do not click suspicious links.
  4. Keep software updated.
  5. Do not share OTPs or passwords.
  6. Use trusted websites and applications.
  7. Back up important data regularly.

9. How to Learn Cyber Security

  1. Learn computer fundamentals.
  2. Understand networking basics.
  3. Learn Linux and operating systems.
  4. Study Python programming.
  5. Understand web security.
  6. Practice in legal cybersecurity labs.
  7. Learn security principles and ethical hacking.

10. Career Opportunities

  • Cyber Security Analyst
  • Security Engineer
  • Network Security Administrator
  • Digital Forensics Analyst
  • Application Security Engineer
  • Information Security Specialist

11. Conclusion

Cyber Security is important in today's digital world. It protects our devices, networks and personal information. Learning cyber security helps us use technology safely and responsibly.
